# 阿龍记账 · Cindy 插件

本地个人账本、图片记账、订阅和生活提醒。版本 **0.3.0**，插件标识 liang-ledger，聊天指令 **$记账**。使用 Cindy Library SQLite，无需 ALOONG 服务器、账号、Node 或 Android 服务。

## 安装与使用

将 plugin/liang-ledger-0.3.0.cindy 导入 Cindy，确认安装权限。打开 Cindy 左侧“更多 → 阿龍记账”。更新后关闭旧工作台再打开。临时 HTTP 预览不连接真实账本。

- 记账：记录收入、支出，查询和编辑账单，月度汇总、分类统计。
- 订阅：自然周、自然月、自然年；用户确认已扣款才入账，可跳过、暂停、归档。
- 提醒：聊天或工作台创建一次性提醒，支持改期、完成、取消，显示计划时间和投递状态。
- 图片：Cindy 对话中发送支付截图或小票，并说“$记账，把这张图记入账本”。

## 提醒

新建 Cindy 对话，引用 $记账，例如“明天早上八点半提醒我喝药”。Cindy 先用 get_summary(contextOnly=true) 读取执行电脑的当前日期与时区，再调用 create_reminder，返回明确日期和时区。

工作台中点“添加提醒”，填写内容和时间。选择器使用当前查看设备时区，保存成 UTC；列表按记录的 IANA 时区显示。手机与电脑时区不同时请核对显示。提醒不会产生账单。

插件采用 launch: resident，Cindy 运行且插件启用时轻量常驻，只保留一个定时器，按最近到期时间安排，最长每30秒检查一次。工作台可以关闭，开发工具无需运行。

提醒是 Cindy **屏幕顶部轻提示**，不承诺声音、震动、系统通知中心或手机锁屏推送。电脑须唤醒、Cindy须运行；退出、睡眠、关机或插件停用时不能即时提示，恢复后补报。Chromium 后台调度与系统负载可能造成延迟，不能代替医疗用途的系统闹钟。

sent 表示宿主接受显示请求，不代表用户看到；failed 延后重试，uncertain 表示调用过程中中断、结果待核实，不自动重复发送。已提示项目保留待办，可标为完成。宿主对提示有5秒限速。提醒触发不调用模型、不产生推理费用。

## 图片自动记账

图片由**当前 Cindy 对话的视觉模型**识别。插件接收明确字段与 Host 交接的原图指纹，校验后原子保存。当前对话模型需支持图片，不需要独立识图服务和额外网络权限。

金额、币种或日期不清楚时先询问。只支持人民币；区分实付、优惠、余额与退款，不把小票合计和分项重复相加。同批最多20笔、4张图片；同一原图再次提交返回原账单。裁剪或重新截图改变指纹，无法据此判断同一现实交易，仍需核对。

record_image_bills 的 dryRun=true 只校验不入账。原图通过 ghost_call 顶层 attachments 交接，不能手填本机路径冒充图片。图片和账本保留在用户 Cindy 数据空间，不提交到源码仓库。

## 文本 AI 与模型

工作台“AI 录入”把一句话解析成账单或订阅草稿，核对后保存。使用插件详情“模型与任务”所选模型；图片识别使用对话当前视觉模型，两者分别配置。模型调用可能产生费用。插件不读取 API Key。

## 数据

人民币金额以整数分存储；自然周期保留月底锚点，闰年恢复2月29日。写入带 requestId，超时查询原请求；同编号不同内容拒绝。编辑使用 revision 防覆盖。

JSON 导出账单、订阅、周期处理和提醒；CSV仅账单，单位分。导入恢复、共享账本、服务器同步、手机离线记账不在本版范围。手机依赖绑定电脑在线。

## 开发

源码在 src/，可打包内容在 plugin/，脚本只写项目目录：

    python -B -X utf8 scripts/build.py
    python -B -X utf8 scripts/verify.py
    python -B -X utf8 scripts/qa_session.py start
    python -B -X utf8 scripts/qa_session.py stop
    python -B -X utf8 scripts/cleanup.py

测试需要已有 Node 24+，插件运行不需要。预览使用独立测试账本并复制宿主 CSP。清理把明确缓存移入 Windows 回收站，不永久删除。

最低 Cindy 0.1.125；核对宿主源码提交 ac785430449042f120a296b881a25ae52333f1e1。发布以 reports/ 实际回执为准，打包、提审和上架分别报告。
